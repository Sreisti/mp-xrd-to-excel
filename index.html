XRD → Excel

Convert the "XRD JSON" file downloaded from a Materials Project material page into a formatted Excel sheet of 2Θ and hkl values.

How to get the JSON file

  1. Open a material's page on legacy.materialsproject.org, e.g. mp-492 (TiN).
  2. Click the "X-Ray Diffraction" tab.
  3. Pick a radiation source (Cu, Ag, Mo, Fe) if you want a different wavelength.
  4. Click the "XRD JSON" button above the plot and save the file (e.g. mp-492.json).
  5. Drop that file (or several, one per material) below.
